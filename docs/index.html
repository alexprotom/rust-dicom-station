What it does

A complete workspace for DICOM and radiotherapy data.

Load studies, inspect image geometry, compare datasets, work with radiotherapy objects and run analysis workflows from one native application.

01

DICOM & RT-DICOM

CT, MR and PET series, RTSTRUCT, RTDOSE, RTPLAN, SEG, registrations and treatment records.

02

Linked MPR & comparison

Patient-space axial, sagittal and coronal views with linked navigation and multi-dataset comparison.

03

Registration

Rigid, B-spline and landmark-based workflows with displacement statistics, vector fields and fusion.

04

4D & motion analysis

Phase grouping, registration, structure propagation, motion metrics, ITV generation and CSV export.

05

Segmentation

Interactive segmentation plus native implementations of TotalSegmentator, SegVol and MedSAM2 workflows.

06

MCP support

Through Model Context Protocol (MCP), assistants can load, segment, register, propagate, analyse and export DICOM data programmatically — including automated processing across entire cohorts.

Quick start

Build the release version and launch it with the bundled example dataset.

shell
$ cargo build --release
$ cargo run --release -- \
    example_data/lung_p1_4DCT_phase_000

No data at hand? The application can generate a complete synthetic RT study!
