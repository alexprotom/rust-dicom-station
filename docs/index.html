Rust DICOM
Station

A native DICOM and radiotherapy station for research, analysis and QA, written entirely in Rust. View and compare complete RT studies, register images and propagate structures, contour and auto-segment, analyse dose and 4D motion, keep your own PACS, and automate it all with workflows or an AI assistant, on Windows, Linux, macOS, Android tablets, iPad and iPhone.

What it does

A complete workspace for DICOM and radiotherapy data.

Load complete studies, inspect image geometry, compare workspaces, work with radiotherapy objects, keep patients in a PACS and run analysis workflows from one native application. Every engine, from registration to the segmentation networks, is re-implemented in Rust, with no Python or C++ framework behind it.

01

DICOM & RT-DICOM

CT, MR and PET series, RTSTRUCT, RTDOSE, photon and ion RTPLAN, DICOM SEG, planar images, spatial and deformable registrations and treatment records, from folders or single files, with or without a volume.

02

Linked MPR & comparison

Patient-space axial, sagittal and coronal views in rows you lay out yourself, the 3D scene among them, and up to four workspaces side by side with the crosshair, slice and zoom synced.

03

Registration

Rigid and B-spline after elastix, dense B-spline and landmark warp after plastimatch, and registration by structures, with Dice, displacement statistics, Jacobian, vector fields and fusion.

04

4D & motion analysis

Phase grouping, registration, structure propagation, motion metrics, ITV generation, structure comparison and CSV export, and cine playback through the phases of a 4D group.

05

Contouring & structures

Polygon, spline, freehand, brush and live-wire tools with interpolation, Boolean operations with margins in patient directions, generators from grey levels or isodose, and the body contour on CT and MR.

06

Segmentation

81 automatic models (TotalSegmentator, the nnU-Net v1 tumour models, MRSegmentator, lungmask, MONAI, CT-FM, VISTA-3D, NV-Segment-CTMR), your own nnU-Net models, and the prompt engines SegVol, MedSAM2 and nnInteractive, all rebuilt natively for the CPU or any GPU.

07

Dose, DVH & DRR

Dose colorwash and isodose lines, cumulative and differential DVHs with D95%, D2cc and V20Gy metrics and protocol constraints, and DRRs with a beam's-eye view from an RTPLAN beam.

08

Workflows

The program's own steps wired into a graph in a node editor, saved as a small file and run again on other data: in the background, step by step in the viewer, or as a batch over a folder of patients.

09

PACS & PACS server

This station's PACS shows cohorts, patients, studies and series from one or more storage folders with one catalog; select several rows to load, rename, move between cohorts or into other folders. The optional rds-pacs server shares it with other stations over HTTPS.

10

MCP support

Through the Model Context Protocol (MCP), assistants can load, segment, register, propagate, analyse and export DICOM data programmatically, including saved workflows and processing across entire cohorts, with patient identifiers kept out.

11

Export & tools

DICOM export with an editable tag table, a folder anonymizer with consistent UID regeneration, a model manager for every downloadable weight and a synthetic RT-study generator.

12

One program, every platform

The same viewer on Windows, Linux, macOS, Android tablets, iPad and iPhone, drawing through wgpu (Vulkan, DirectX 12, Metal or OpenGL); a CPU-only build runs without the GPU inference backend.

Or install it with a package manager

The same release, kept up to date by the package manager.

Windows · winget
>winget install RDS.RustDICOMStation
>winget upgrade RDS.RustDICOMStation
Linux · Snap Store or Flathub
$sudo snap install rust-dicom-station
$flatpak install flathub io.github.alexprotom.rust-dicom-station
  • Latest release: loading. Every file comes from GitHub Releases.
  • Windows: a newer installer updates the installed version in place, and Update Rust DICOM Station in the Start menu fetches the newest release.
  • Linux: the AppImage needs no installation; the snap and the Flatpak update by themselves.
  • macOS: About This Mac says which of the two images to take; until a build is notarised, its first launch needs right-click ▸ Open (macOS notes).
  • Android: 64-bit ARM tablets with Android 11 or later; allow the installation from this source when Android asks. It is not in Google Play (why).
  • iPad and iPhone: the .ipa installs through TestFlight, an ad hoc profile, or a tool that re-signs it with your own Apple ID (how).

Quick start

From source, with a Rust toolchain (rustup.rs): build the release version and open the bundled example patient.

shell
$ cargo build --release
$ cargo run --release -- \
    data-test/TCIA_4D-LUNG/P102/4DFBCT+RTS

No data at hand? The application can generate a complete synthetic RT study, and Tools > Download test data fetches the bundled real 4DCT study from GitHub into an installed copy.
